# RockPaperScissors

**RockPaperScissors** là trò chơi Oẳn Tù Tì (Búa – Kéo – Bao) được triển khai bằng **Solidity** trên **Remix IDE**, kết hợp với giao diện web để người chơi trải nghiệm trực tiếp trên trình duyệt.

## ⚡ Công nghệ sử dụng

- **Frontend:** HTML, CSS, JavaScript
- **Smart Contract:** Solidity (Remix IDE)
- **Blockchain:** Ethereum Testnet (Sepolia, Goerli…)
- **Công cụ hỗ trợ:** MetaMask, Prettier, Git

## 🚀 Hướng dẫn chạy dự án

### 1. Cài đặt môi trường
- Cài đặt [Node.js](https://nodejs.org/) (tuỳ chọn nếu muốn dùng build tools)
- Cài đặt [MetaMask](https://metamask.io/) để kết nối blockchain
- Mở [Remix IDE](https://remix.ethereum.org/) để deploy smart contract

### 2. Triển khai Smart Contract
1. Mở file `contracts/RockPaperScissors.sol` trong Remix IDE  
2. Chọn **Solidity Compiler** và compile contract  
3. Kết nối Remix với **Injected Web3** (MetaMask)  
4. Deploy contract lên **Ethereum testnet**  
5. Copy **Contract Address** nếu muốn kết nối với frontend

### 3. Chạy frontend
1. Mở folder `frontend/`  
2. Mở file `index.html` bằng trình duyệt  
3. Kết nối ví MetaMask và chơi trò Oẳn Tù Tì  

## 💻 Tính năng

- Người chơi chọn **Búa, Kéo, Bao**  
- So sánh kết quả theo luật Oẳn Tù Tì  
- Tích hợp **smart contract** đảm bảo tính minh bạch  
- Giao diện web đơn giản, dễ thao tác
